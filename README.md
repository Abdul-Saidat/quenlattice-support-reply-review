# quenlattice-support-reply-review

A page where a support agent reads a customer question, the AI's draft, and the approved policy.

## How to get the repository

1. Clone the repository

```bash
git clone https://github.com/Abdul-Saidat/quenlattice-support-reply-review.git
```

2. Change directory to the project folder

```bash
cd quenlattice-support-reply-review
```

3. Ensure you are on the right branch

```bash
git switch sprint/month-01-2-ca72512a
```

## How to open the page

Double-click `public/index.html`, or open it with the Live Server extension in VS Code.

## What you'll see

The agent can compare the AI's draft with the approved policy.

- Customer question: The question the customer asked.
- AI-drafted reply: Text response from the AI assistant.
- Approved knowledge: Shows the approved policy the draft is based on, with its title, source, and policy text.

## Sample data

The sample content is fictional and is not connected to real customers or a real company system.
